# Android Platform Reference
Version: 3.0 | Updated: 2026-09-09

## Structure
- Prefer standard top app bars, navigation bars, sheets, dialogs, and menus.
- Support predictive back and preserve app state when users leave and return.
- Handle system bars, cutouts, keyboard, rotation, and low-memory devices.

## Final Rule

Android UX should feel native, fast, and trustworthy.
