# Brand Pattern: Cal.com

## Lessons & Core Philosophy
Cal.com uses grayscale restraint and confident monochrome. The brand is bold because it relies on typography, whitespace, and controlled contrast instead of color noise.

### Key Characteristics
- Grayscale brand palette
- Strong typography hierarchy
- Layered shadow system
- Product screenshots as hero content

## Final Rule
Use the structure, not the literal brand clone.
