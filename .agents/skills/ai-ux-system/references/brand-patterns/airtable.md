# Brand Pattern: Airbnb

## Lessons & Core Philosophy
Airbnb relies heavily on a white canvas with photography-first layouts. Their signature typography uses negative letter-spacing for a warm, intimate feel. Depth is created by layered shadows and strong border contrast.

### Key Characteristics
- Pure white canvas with Rausch Red accent
- Warm, rounded typography
- Palette-based token system
- Multi-layer red-tinted or neutral shadows
- Photography-first listings and cards

## Final Rule
Learn the system behavior, not the exact visual duplication.
