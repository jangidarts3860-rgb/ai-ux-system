# Brand Pattern: Warp

## Lessons & Core Philosophy
Warp reimagines the terminal as a modern app with a strong dark canvas and semantic accent colors. It is notably crisp, fast, and built for technical users.

### Key Characteristics
- Dark workout-like canvas
- Monospace-first clarity
- Semantic accent color system
- Structured blocks and inline suggestions

## Final Rule
Use the terminal logic and dense information patterns, not the direct clone.
