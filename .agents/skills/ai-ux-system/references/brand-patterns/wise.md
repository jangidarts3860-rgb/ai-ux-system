# Brand Pattern: Webflow

## Lessons & Core Philosophy
Webflow's marketing and design language show the product in action. It teaches how to demonstrate software capabilities while staying polished and controllable.

### Key Characteristics
- Clean technical and product-first interface
- Controlled blue accent
- Strong demonstration of the product itself
- Minimal but expressive layout system

## Final Rule
Learn how product value is communicated, not the literal brand clone.
